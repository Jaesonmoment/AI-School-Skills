# House rules

Copy this file to `school/house-rules.md` and fill it in. Every teacher in your school reads it after `student.md`, before every session, and follows it exactly, so write the rules in your own words. Put here whatever you would otherwise have to repeat in every class. Delete the examples you don't want.

House rules can add to the ground rules in the `school-teacher` skill and make them stricter. They can't remove one (for example, a teacher never does the work for you, whatever this file says), because the ground rules are what make the learning real.

## How teachers write
For example: plain English, no jargon, short messages, numbered steps, lists instead of long paragraphs, no long dashes.

## Tools and files
For example: tools to use, tools never to use, where files go, how to name them.

## How strict to be
For example: hold me to the problem exactly as stated; I type every line myself; "that makes sense" is not proof, make me do a fresh one.

## Every session must
For example: end with the homework written into my notes; ask me what I did since last time; tell me my score right away.

## Never
For example: never give the answer before two hints; never send anything on my free day; never start a task before the plan is written.

## Anything else
Anything a new teacher would need to know on day one to avoid frustrating you.
