# <Subject> pack

This is a subject pack: extra knowledge for one subject that plugs into the `school-teacher` skill and the skills it points to. A pack adds to them. It never replaces the ground rules, the lesson routine or the student's house rules. Delete any section you don't need, and keep the frontmatter above so the skill loads.

To use it: copy this file to a folder named after the pack (for example `luau-pack/SKILL.md`), fill it in, and install it like any other skill. Teachers use a pack when it is installed and ignore the rest of this file.

## What this pack covers
The subject, the level it goes from and to, and who it is for.

## Course map
The order to teach it in: a list of skills from first to last, each with what would prove the student has it. The teacher starts its skill map from this list and checks it against its own research.

## Trusted sources
Courses, books, documentation and teachers you trust for this subject, with a link and one line on what each is good for. The teacher still fact-checks before anything reaches the student.

## Tool setup
What the student needs installed or open before the first hands-on lesson, and one tiny check that it works (open the tool, run one line, see the expected result).

## Conventions
How things are done in this subject: naming, style, how work is laid out, what "done" looks like.

## Common misconceptions
Mistakes beginners make, the likely cause of each, and the question or task that exposes it.

## Exercises and projects
Your own tasks, with their requirements stated up front, and the project the student builds by the end.

## Off limits
Topics this pack does not cover, for example because another class owns them.
